# Review the source basis

Use these references to understand the design choices and their limits. Contents and license files were inspected on **2026-10-21**. Revisions below pin the material reviewed; later changes require another review. This project adapts the Apache-2.0 Go checkout of [tphakala/jev-mcp](https://github.com/tphakala/jev-mcp/tree/f51a9267f74a641f44f90fa5e1a8d3125edc9a35), initially at `f51a9267f74a641f44f90fa5e1a8d3125edc9a35`. Existing `LICENSE`, copyright headers, and upstream contribution/security documentation remain in place.

The references informed original Go implementations and original synthetic fixtures. Their servers, prompts, benchmark records, and datasets are not bundled. A documentary-support scale is a proposed synthesis, not a universal research standard or a calibrated measure of truth.

## Reverify provider and protocol contracts

The current authoritative contracts are linked below. They were reviewed on **2026-10-21**; external documentation can change independently of this checkout.

| Contract | Verified source and operational meaning |
| --- | --- |
| TypeSafe index and schemas | [Documentation index](https://docs.typesafe.ai/llms.txt), [System One](https://docs.typesafe.ai/api/system-one), [OpenAPI](https://api.typesafe.ai/openapi.json): bearer-authenticated `POST /v1/systemone` with model, state and a question map. [Model discovery](https://docs.typesafe.ai/api/list-models): authenticated `GET /v1/models`. |
| Primitive meaning | [Choice](https://docs.typesafe.ai/primitives/choice): selected-option probability and confidence differ. [Score](https://docs.typesafe.ai/primitives/score): zero-indexed ordered criteria, legend, distribution, and probability-weighted score; fractional values must not be rounded into semantic certainty. [Noul](https://docs.typesafe.ai/primitives/noul): probability of the proposition being true, with no separate native confidence field. |
| Citation checks | [Citation-checking cookbook](https://docs.typesafe.ai/cookbooks/citation_check): deterministic quote matching before an evidence-relation question. Example thresholds are illustrative and do not calibrate this application. |
| Go MCP SDK | [Pinned v1.8.0 SDK](https://github.com/modelcontextprotocol/go-sdk/tree/v1.8.0), [protocol documentation](https://modelcontextprotocol.io/specification): shared typed tools and stdio/Streamable HTTP transports. Runtime tests, rather than SDK presence, establish this server's transport behavior. |
| Secure MCP Tunnel | [Guide](https://developers.openai.com/api/docs/guides/secure-mcp-tunnels), [official external client](https://github.com/openai/tunnel-client), [client configuration](https://github.com/openai/tunnel-client/blob/main/docs/configuration.md): local stdio or HTTP forwarding, runtime control-plane key, separate tunnel permissions. The documented envelope is 10 MiB and 120 seconds including queue time; keep this server's input and deadline below it. |
| ChatGPT connection and permissions | [Custom MCP setup](https://developers.openai.com/api/docs/guides/custom-mcp-server), [connect/test](https://developers.openai.com/plugins/deploy/connect-chatgpt), [MCP server requirements](https://developers.openai.com/plugins/build/mcp-server), [authentication](https://developers.openai.com/plugins/build/auth), [plugin surfaces](https://developers.openai.com/plugins/concepts/plugins), [review requirements](https://developers.openai.com/plugins/deploy/app-review). Platform tunnel permissions, ChatGPT workspace permissions, provider credentials, and server authentication are separate. Web setup does not establish account-specific iOS availability. |

## Preserve reuse boundaries

Keep the root Apache-2.0 license and upstream notices when distributing this derivative. If future work copies code or text, add the applicable copyright/license notice and review its license first. Do not import AVeriTeC research data into permissive fixtures, or conflate SciFact's three licenses. The fixture suite in this checkout must use original labels and synthetic source passages. No inspected research scale establishes universal source reliability or model accuracy.
